Data Flow:
─────────
1. Arduino reads DS18B20 every 5 seconds
2. Arduino sends: "TEMP <cabin_id> <value>\n" via USB serial
3. Raspberry Pi receives via /dev/ttyUSB0 (or ttyUSB1, ttyUSB2)
4. RTOS updates cabin temperature and displays
5. If temp > 45°C: Arduino sends "EMERGENCY <cabin_id>\n"
6. RTOS triggers passenger emergency task (Priority 2)
7. Emergency alerts continuously until CLEAR command

  ASSEMBLY CHECKLIST
═══════════════════════════════════════════════════════════════════════════

Step-by-step assembly verification:

 [ ] 1. Place Arduino Nano on breadboard (straddling center gap)
 
 [ ] 2. Identify DS18B20 pins (flat side facing you: 1-2-3 left-to-right)
        Pin 1 (Left)   = GND   (Black wire)
        Pin 2 (Middle) = DATA  (Yellow wire)
        Pin 3 (Right)  = VCC   (Red wire)
 
 [ ] 3. Insert DS18B20 into breadboard (3 pins in consecutive rows)
 
 [ ] 4. Connect GND:
        Arduino GND pin → DS18B20 Pin 1 (black jumper wire)
 
 [ ] 5. Connect VCC:
        Arduino 5V pin → DS18B20 Pin 3 (red jumper wire)
 
 [ ] 6. Connect DATA:
        Arduino D2 pin → DS18B20 Pin 2 (yellow jumper wire)
 
 [ ] 7. Install pull-up resistor (4.7kΩ Yellow-Violet-Red):
        One leg to DS18B20 Pin 2 (DATA)
        Other leg to DS18B20 Pin 3 (VCC)
 
 [ ] 8. Visual inspection:
        - No crossed wires
        - Resistor legs not touching GND
        - DS18B20 orientation correct
        - All connections secure
 
 [ ] 9. Connect USB cable to Arduino
 
 [ ] 10. Arduino LED lights up (power indicator near USB)
 
 [ ] 11. Upload temp_sensor.ino sketch
 
 [ ] 12. Open Serial Monitor (115200 baud)
 
 [ ] 13. Verify output:
         "Found 1 DS18B20 sensor(s)"
         "[Reading 1] Cabin 0: XX.XX°C"
 
 [ ] 14. LED behavior:
         - 3 blinks on startup
         - 1 blink every 5 seconds (reading)
         - 2 blinks every 10 seconds (sending)


═══════════════════════════════════════════════════════════════════════════
  TROUBLESHOOTING GUIDE
═══════════════════════════════════════════════════════════════════════════

Problem: "Found 0 DS18B20 sensor(s)"
─────────────────────────────────────
  ✓ Check DS18B20 orientation (Pin 1=GND, 2=DATA, 3=VCC)
  ✓ Verify 4.7kΩ resistor between DATA and VCC
  ✓ Ensure D2 pin connection is solid
  ✓ Try different digital pin (change DS18B20_PIN in code)


Problem: Temperature reads -127.00°C
─────────────────────────────────────
  ✓ Sensor disconnected or bad connection
  ✓ Missing pull-up resistor (critically important!)
  ✓ Check power: 5V and GND properly connected
  ✓ Try adding delay after sensors.requestTemperatures()


Problem: Temperature reads ~85°C constantly
────────────────────────────────────────────
  ✓ Sensor still initializing (wait 5-10 seconds)
  ✓ Reset Arduino (press reset button)
  ✓ Check for short circuit between VCC and DATA


Problem: LED stays solid ON
────────────────────────────
  ✓ Sensor error detected by code
  ✓ Check Serial Monitor for error message
  ✓ Verify wiring and resistor placement


Problem: No serial output / garbage characters
───────────────────────────────────────────────
  ✓ Set Serial Monitor to 115200 baud
  ✓ Close and reopen Serial Monitor
  ✓ Press Arduino reset button
  ✓ Check USB cable (must be data cable, not power-only)

═══════════════════════════════════════════════════════════════════════════
  SAFETY NOTES
═══════════════════════════════════════════════════════════════════════════

  ⚠️  DS18B20 maximum temperature: 125°C (257°F)
      Do NOT use with boiling water or direct flame!

  ⚠️  Always use 4.7kΩ pull-up resistor
      Sensor may work intermittently without it but will fail randomly

  ⚠️  Check polarity before powering on
      Reversed VCC/GND can damage DS18B20 permanently

  ⚠️  USB ports supply limited current (~500mA)
      For >10 sensors, use external 5V power supply

  ✅  DS18B20 is ESD-sensitive - handle with care
  ✅  Use proper wire gauge for permanent installations
  ✅  Waterproof sensors available for outdoor/harsh environments
